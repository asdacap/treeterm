Main Rust counterparts: `treeterm-model/src/app_store.rs` (`AppStore`: connections, `on_status`, `connect_remote`, `disconnect`, `retire`), `treeterm-model/src/apps.rs` (`AppRegistry`), `treeterm-model/src/session_store.rs` (`SessionStore::new`, `handle_external_update`, `dispose`, `on_settings_changed`, `workspace_for_path`, `unmerged_sub_workspaces`), `treeterm-app/src/app_view.rs` (`AppView::sync`, `open_pending_workspace`, `request_close`, menu actions), `treeterm-app/src/main.rs`, `treeterm-app/src/cli.rs`, `treeterm-model/src/session_names.rs`, `treeterm-model/src/traffic.rs`.

Architecture note: Electron keys session stores by a random `session-<ts>-<rand>` id and keeps a store alive (with a status) across disconnects; the port keys `SessionSlot`s by `ConnectionId`, keeps the connection state in `ConnState`, and builds a fresh `SessionStore` for each `Connected` generation, retiring (disposing) the old one on any status change after `Connected`.
