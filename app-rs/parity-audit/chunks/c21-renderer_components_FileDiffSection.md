# c21-renderer_components_FileDiffSection

Verified: +2 rows, 20 rows changed

How the port is built: Electron draws one `FileDiffSection` per changed file. Each section lazy-loads both sides of its file on scroll, then draws them with Pierre. The Rust port loads one unified patch for the whole view (`git diff -M -U1000000`, `review.rs:988 diff_request`) and draws every file in one virtualized GPUI Kit `Diff` (`DiffState`, `vendor/gpui-component/src/diff/state.rs:223 list: ListState`). Each file's header is a Kit annotation drawn by `review_view/stacked.rs` (`file_header`, `header_row`, `sticky_header`).
