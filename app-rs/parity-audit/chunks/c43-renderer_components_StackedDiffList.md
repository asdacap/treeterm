# c43-renderer_components_StackedDiffList

Verified: +5 rows, 15 rows changed

Architecture note: Electron loads each file's full before/after contents lazily, one file at a time (`loadFileContents` per section), and renders them with Pierre. The port fetches one whole-file patch (`git diff -M <FULL_CONTEXT>` plus untracked files) for the entire view in `ReviewModel::reload_quietly` (app-rs/crates/treeterm-model/src/review.rs:905) and shows it in one GPUI Kit `Diff` (app-rs/crates/treeterm-app/src/review_view/stacked.rs:106 `ReviewView::stacked`). As a result, Electron's per-file load/settle machinery has no counterpart. User-visible per-file loading, error and refresh states are reported below as PARTIAL.
