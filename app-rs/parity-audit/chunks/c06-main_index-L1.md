Scope: `src/main/index.ts` lines 1-622 (module state, loading/main window, reconnect helpers, PTY / daemon / session / clipboard / dialog / settings / fs IPC handlers, `sendExecEvent`). Exec start/kill, sandbox, local/ssh connect, port forwards, app lifecycle (L623+) belong to the next chunk.

Architecture note: Electron main keeps per-window registries (PTY streams, file watches, session watches) behind IPC and re-establishes them on reconnect. The port is single-process and single-window. Each `Connected` status builds a new `DaemonConnection` (main + session channels) and a new `SessionStore`, which opens its own session watch and workspace-file watches (`app_store.rs:218 on_status`). Terminal attachments belong to `TerminalModel`. Most registry bookkeeping rows are therefore NA, and the capability behind them is mapped.
