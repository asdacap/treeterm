# c08-main_ipc_ipc-server

Verified: +3 rows, 8 rows changed

`ipc-server.ts` is pure IPC plumbing: each method registers one `ipcMain.handle`/`ipcMain.on` channel or emits one main→renderer event. The handler bodies live in `src/main/index.ts` and `src/main/menu.ts`, which other chunks audit (c06/c07). Each row below names the capability behind a channel and maps it to the port. The port is one process, so the GPUI views call model/core code directly and no IPC sits between them. Where a channel only proxies a daemon RPC, the row is SHARED and points at the Rust client call for the same RPC.
